# Julian Vidal - Portfolio & Resume

A responsive, single-page portfolio and resume website built with HTML, CSS, and vanilla JavaScript.

## Features
- **Responsive Design:** Adapts to desktop and mobile devices.
- **Scroll Animations:** Smooth fade-in effects as you scroll down the page, managed by an Intersection Observer.
- **Accessible Design:** Meets WCAG AA contrast standards.
- **Clean UI:** A minimalist, professional aesthetic for presenting work experience, projects, skills, and education.

## Technologies Used
- HTML5
- CSS3 (with CSS variables for theming)
- JavaScript (vanilla)

## Running Locally

Since this is a static website, you do not need any build tools to run it.

1. Clone the repository.
2. Open `index.html` directly in your web browser.

Alternatively, you can serve it locally using Python to avoid CORS issues if you add external assets later:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
